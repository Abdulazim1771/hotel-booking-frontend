# Hotel Booking System React app

A minimal React + TypeScript application using Vite. This directory is the application root; `src/` inside it contains the React source files. See the [design guide](../design/MASTER.md) for the planned hotel screens and styling.

From this directory, install dependencies and start the development server:

```powershell
npm install
npm run dev
```

Open the local URL printed by Vite, normally `http://localhost:5173`.

```powershell
npm run typecheck
npm run build
npm run preview
```

The application currently renders a starter page. Hotel features and backend integration are not yet implemented.
